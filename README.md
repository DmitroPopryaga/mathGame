# Слаймовая ферма — математическая игра

Мобильная браузерная игра для тренировки математики в начальной школе. Ребёнок решает примеры и текстовые задачи, собирает звёзды и открывает слаймов. Прогресс хранится в `localStorage` браузера.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Добавьте этот проект в репозиторий и отправьте ветку `main`.
3. В настройках репозитория откройте **Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.
4. GitHub Pages опубликует `index.html` как главную страницу проекта.

## Структура

```text
mathGame/
├── index.html   # разметка, стили и логика игры
├── README.md    # описание, запуск и публикация
└── .gitignore   # локальные и временные файлы, которые не нужно отправлять
```

## Данные игрока

Звёзды, коллекция и настройки сохраняются локально в браузере и не загружаются в репозиторий.
